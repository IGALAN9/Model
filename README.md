# Model
Model dari klasifikasi Hoax untuk project akhir CekCok
Project ini dijalankan pada Google Collab.
Repository ini digunakan untuk mencatat perubahan yang pernah di lakukan

## Menjalankan aplikasi Streamlit

Install dependensi lalu jalankan:

```bash
pip install -r requirements.txt
streamlit run streamlit_app.py
```

Untuk deployment di Streamlit Community Cloud, pilih `streamlit_app.py`
sebagai Main file.
